WHAT THIS EXPERIMENT SHOWS

Order is not the same as settling.

All three bodies attract each other. The initial period ratio is 2.05, and the total initial linear momentum is zero. The circular starting state develops perturbations; it has not demonstrated spontaneous capture into a permanent, motionless 2:1 lock.

The optional candidate starts with chosen eccentricities and phases. Its angles stayed bounded in a finite native test. Oscillation around a resonant configuration is called libration; it does not have to disappear for a phase relationship to remain bounded. These plots are diagnostic evidence, not a universal “resonance percentage.”

This viewer replays 2048 simulated seconds of exported data. Positions are interpolated between recorded samples. Changing speed or camera does not run a new physics calculation. To change masses or initial conditions, use the native application and regenerate the data.
